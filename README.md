# 水滴 QQ

**水滴 QQ（ShuDiQQ）** 是一款本机运行的 QQ NT 多账号管理客户端。通过 Electron 桌面界面管理账号，以本地 C++ 宿主调度 QQ 进程，提供消息、事件、API、WebSocket 和插件扩展能力。

## 主要功能

- **多账号管理**：扫码、密码和快速登录，每个账号使用独立进程与会话，可集中查看状态并启停账号。
- **消息与事件**：处理群聊、私聊、临时会话消息，以及群成员变动、撤回、禁言、管理员变更和申请事件。
- **API 与 WebSocket**：181 个公开 API，支持正向和反向 WebSocket，以 OneBot 风格字段对接机器人及自有程序。
- **插件扩展**：导入插件包、加载开发目录、启停和配置插件，支持插件设置、热重载与版本回滚。
- **多语言 SDK**：支持 JavaScript、TypeScript、x64 C/C++ 和 32 位易语言插件，SDK 单独分发。
- **异常处理**：账号掉线重连、异常日志记录和资源状态查看。
- **在线更新**：校验更新文件，更新失败回滚，并保留账号数据、插件及本地配置。

## 安装使用

1. 下载对应版本的 `.exe` 安装器，升级前完整退出旧客户端及其管理的 QQ 进程。
2. 运行安装器，建议安装到 `D:\ShuDiQQ` 等纯英文短路径。
3. 安装完成后，通过桌面快捷方式或安装目录中的 `ShuDiQQ.exe` 启动客户端。
4. 登录授权账号、添加 QQ 账号，并按需要配置插件或 WebSocket。

## 运行环境

- Windows 10 / 11 x64；Windows Server 2016 及更新版本需启用桌面体验。
- 安装后约占用 1.5 GB，需预留安装校验和后续更新空间。
- Microsoft Visual C++ 2015-2022 Redistributable x64。
- 可正常访问授权服务；系统日期、时间和时区应保持准确。

Windows 7 和旧版 Windows Server 不作为推荐运行环境。

## 技术架构

| 组成 | 说明 |
| --- | --- |
| 桌面客户端 | Electron + Vue 3 + Element Plus |
| 本地宿主 | C++，负责账号进程、插件和本地接口调度 |
| QQ 桥接 | 注入 QQ NT 进程，处理消息、事件及 API 请求 |
| 服务端 | 与管理前端分离部署，负责授权、会话和版本管理 |

本仓库用于产品介绍与客户端安装器分发。源码和 SDK 不在此安装器中分发。

## 使用说明

- 使用内置且已适配的 QQ NT 版本，不要单独替换为未经确认的 QQ 版本。
- 群管理、撤回和资料操作受账号权限及 QQ 内核状态限制，失败时请检查返回信息。
- 图片链接可能过期，长期使用的媒体内容应及时保存。
- 首次使用建议先在自己的测试账号上验证配置和插件；不承诺 QQ 升级后的自动兼容或长期无人值守稳定性。
- 请遵守适用规则及 QQ 服务条款，不用于骚扰、垃圾消息或其他滥用行为。
